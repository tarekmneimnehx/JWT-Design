Brand call-to-action button — use for any primary or secondary action; renders as a link when `href` is set.

```jsx
<Button variant="primary" size="lg" withArrow href="#contact">Start your project</Button>
<Button variant="outline">View all projects</Button>
<Button variant="outline-inverse">Explore expertise</Button>   {/* over photography */}
<Button variant="accent" uppercase>Enquire</Button>
```

Variants: `primary` (ink), `accent` (taupe), `outline`, `outline-inverse`, `ghost`, `link`. Sizes: `sm` `md` `lg`. Add `withArrow` for the nudging arrow, `uppercase` for the tracked luxury micro-CTA.
