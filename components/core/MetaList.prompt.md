The signature project meta line — one tracked uppercase run of discipline / sector / region / year. Sits above project titles on cards and hero units.

```jsx
<MetaList items={['Interiors', 'Hospitality', 'Dubai', 2024]} />
<MetaList items={['Lighting', 'Spa & Wellness', 'Abu Dhabi', 'In progress']} tone="inverse" size="lg" />
```

The first item renders in taupe so the discipline reads first. Pass `accentFirst={false}` to flatten.
